# **App Name**: InventarioPlus

## Core Features:

- Authentication and Roles: Secure user authentication with role-based access control (Admin, Sales).
- Inventory Management: Manage products with photos, prices, and stock levels, import data from Excel.
- Import Management: Handle legal regimes with FOB, EXN, SIF, DDP, INCOTERMS, manage import quotes with breakdowns and documents.
- Cost and Pricing: Calculate automatic sales prices and profit margins considering operational costs and transport.
- Sales Management: Manage suppliers, clients, unit and lot quotes, and order tracking with filters.
- Dashboard and Statistics: ClickUp-style dashboard with KPIs and statistics for entries/exits.
- Reporting: Generate admin and sales reports (weekly, monthly, yearly), inventory status, order summaries, import reports with pivot tables exportable to Excel/PDF.
- Product Insights: Identify top-selling, highest-profit, worst-selling, and lowest-profit products based on sales and profitability data.

## Style Guidelines:

- Primary color: Leaf Green (#6DA34D) for a fresh, natural feel.
- Background color: Light gray (#F0F0F0) for a clean and modern look.
- Accent color: Dark Gray (#4A4A4A) to provide contrast and a sophisticated feel.
- Body and headline font: 'Inter' sans-serif font for clear readability and modern style.
- Use minimalistic icons related to inventory and sales management.
- Responsive design with options for light and dark mode.
- Subtle transitions for page navigation and data updates.
